This source code repository is being developed by the Concord Consortium to produce the web application called the Common Online Data Analysis Platform (CODAP).

CODAP is an adaptable platform that can be incorporated into online curriculum materials to provide a data analysis and visualization environment. CODAP may also be used as a standalone learning environment for data exploration.

* For more information visit the [CODAP Home Page](https://codap.concord.org).
* [CODAP's current release](https://codap.concord.org/releases/latest)
